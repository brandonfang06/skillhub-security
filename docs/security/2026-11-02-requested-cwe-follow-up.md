| CWE-89 | `JdbcGithubSyncHistoryRepository`: fixed ANY predicates with bound UUID arrays replace runtime IN-list formatting. `JdbcGithubSyncCapacityGate`: a constant, bound nullable-namespace predicate replaces SQL assembly. `JdbcGithubSyncUploadRepository` chooses only constant read/lock statements. `JdbcGithubSyncSchedulePolicyRepository` accepts a boolean mode rather than arbitrary SQL text. |
| CWE-89 | `JdbcGithubSyncTaskRepository`, `JdbcGithubOfficialDiscoveryRepository`, `GithubSyncWorkerPresenceRepository`: constant SQL with separate parameters replaces manual statement callbacks; framework-managed text/UUID arrays are released after success or failure. `JdbcGithubSyncPathPresenceRepository` uses fixed named-parameter batch SQL. `InitialAuthSettingsInitializer` uses a prepared advisory-lock statement and bound bigint key. Original predicates, locks, transaction boundaries and audit behavior remain. Other adapters with constant SQL and already-bound values retain those safe contracts. |
| CWE-601 | `AnonymousDownloadIdentityService`: a private issuer creates, configures and emits a typed servlet cookie, without generic response-header writes or re-reading raw forwarding headers. The class has no redirect operation; forged-host/no-Location, valid reuse, tamper rejection, HTTP/HTTPS state and real Tomcat header behavior are tested. |
| CWE-259 | `tree_live_test.go`: explicit environment credentials or explicit anonymous mode replace automatic borrowing of personal gh credentials; regression credentials are runtime-generated. Fixed public Git commit SHAs remain immutable fixtures, not passwords. Independent tests verify required configuration and that anonymous mode does not access credentials. |

Complete Go-test coverage also exposed a self-executable audit ERROR and an archive-read WARNING. The Linux SIGTERM fixture now invokes the kernel `/proc/self/exe` reference, preserving the actual signal/process/cleanup test. Live archive digesting uses `io.CopyN` with declared size+1; exact, oversized and truncated input tests prove the read bound and fingerprint. No file was renamed or excluded to hide a match.

The SQL edits strengthen interfaces and array-resource ownership where values were already bound; they are not evidence that every old call was exploitable injection. Likewise, no password or open-redirect exploit was demonstrated in the original Git SHA/cookie code. All requested categories received explicit code changes and tests without misclassifying public fixture data as a secret.
